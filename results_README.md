# Results package for run `20260814T033139Z`

This directory holds the artefacts that substantiate the numbers reported in the thesis. It is
deliberately small: per-cell prompt payloads and raw provider responses are not committed, but every
figure that appears in a thesis table can be recomputed from what is here.

Run configuration is recorded in `run_manifest.json`, which pins the run identifier, the generator
model and temperature, the judge model and provider family, the retrieval budget, the embedding
model, the prompt-template SHA-256 stamps, and the code commit the run was produced from.

## Files

| File | Contents |
| --- | --- |
| `run_manifest.json` | Run identifier, models, temperature, retrieval configuration, prompt hashes, code commit |
| `diagnostics.jsonl` | 120 rows, one per cell (requirement x condition). Layer 1 structural metrics and Layer 2 file-verification verdicts |
| `judgments.jsonl` | 140 reconciled pairwise comparisons, per-criterion and overall winners, both presentation orders |
| `judgments_raw.jsonl` | Unreconciled per-order judge output, retained so positional inconsistency can be recomputed |
| `calibration_result.json` | Layer 4 Cohen's kappa, per-criterion agreement, confidence interval, gate outcome |
| `aggregates.json` | Every aggregate quoted in Chapters 4 to 6, regenerated by `scripts/aggregate_results.py` |

Personal data does not appear in any artefact. The calibration files record rating decisions only,
in sheet-position space, with no rater identity.

## Regenerating the aggregates

```bash
python scripts/aggregate_results.py --run-id 20260814T033139Z
```

The script reads the three JSONL and JSON artefacts in this directory, applies the statistical
procedures in `src/analysis/stats.py`, and writes `aggregates.json` together with a printed table
per thesis table above. It calls no external API and requires neither the SEOSS dump nor the Apache
Pig clone, so any reader with the repository alone can verify the reported figures.

## Statistical reading

Non-significant comparisons are reported as not significant rather than as evidence of no effect.
With twenty requirements the design has modest power, so a non-significant result means the study
did not detect an effect at the chosen level, not that an effect is absent.
